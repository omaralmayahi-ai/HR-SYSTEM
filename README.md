# نظام إدارة الموارد البشرية العراقي الموحد (HR System)

نظام متكامل لإدارة الموارد البشرية والرواتب وفق القوانين العراقية النافذة (قانون رواتب موظفي الدولة 22/2008 وتعديلاته، الخدمة المدنية، الملاك، الانضباط، التقاعد الموحد). مبني بـ React و Express وقاعدة بيانات PostgreSQL، والمصادقة بـ JWT و bcrypt.

> المراجعة الشاملة وخطة التطوير: [`docs/review/00-consolidated.md`](docs/review/00-consolidated.md). تعليمات الوكلاء البرمجيين: [`AGENTS.md`](AGENTS.md).

## المميزات الأساسية

1. **إدارة الموظفين**: تسجيل وتحديث بيانات الموظفين بالكامل (الاسم الكامل، رقم الهاتف، الدرجة والوظيفة، الشهادة الدراسية، الحالة الزوجية، عدد الأطفال).
2. **إدارة الرواتب** (موديل الرواتب يُعاد بناؤه وفق [`docs/designs/payroll/requirements.md`](docs/designs/payroll/requirements.md)):
   - توليد الرواتب آلياً بالاعتماد على الدرجة والمرحلة الوظيفية للموظف.
   - حساب مخصصات الشهادات العلمية (دكتوراه، ماجستير، بكالوريوس، إلخ).
   - احتساب مخصصات الزوجية والأطفال.
   - التوقيفات التقاعدية 10% من الراتب الاسمي (قانون التقاعد الموحد 9/2014).
   - مراجعة واعتماد قسائم الرواتب الشهرية.
3. **إدارة الإجازات**: تقديم ومتابعة طلبات الإجازات والرد عليها بالقبول أو الرفض مع تدوين الملاحظات.
4. **العقوبات والإنذارات**: تدوين وتوثيق العقوبات والإنذارات الإدارية للموظفين.
5. **التقييم السنوي**: نظام تقييم الأداء السنوي واحتساب الدرجات وحفظ سجلات التقييم.
6. **الدورات التدريبية**: جدولة الدورات التدريبية وتسجيل الموظفين وتتبع نتائجهم.

## التقنيات المستخدمة

- **الواجهة الأمامية (Frontend)**: React, Vite, Tailwind CSS, Lucide Icons, Recharts.
- **الخلفية (Backend)**: Express.js (TypeScript), tsx, esbuild.
- **قاعدة البيانات**: PostgreSQL (Drizzle ORM).
- **المصادقة وأمن البيانات**: JWT موقّع + bcrypt، وأدوار (مدير/مستخدم/موظف) على الخادم.

## التشغيل

### على Windows (الطريقة المعتمدة)
انقر مرتين على `control-app.bat`: تفتح لوحة التحكم (تنصيب أول مرة، تشغيل/إيقاف، التشغيل الدائم، النسخ الاحتياطي والاستعادة، التحديث من GitHub، فحص النظام). اللوحة تولّد `.env` بمفاتيحه.

من سطر الأوامر:
```bat
control-app.bat status      :: حالة النظام وقاعدة البيانات وآخر نسخة احتياطية
control-app.bat restart     :: (موجه أوامر بصلاحية المدير)
control-app.bat backup -Yes
control-app.bat help
```

### للتطوير
1. انسخ `.env.example` إلى `.env` واضبط `SQL_*`، و`JWT_SECRET` (32 حرفاً فأكثر)، و`LOCAL_DB_ENCRYPTION_KEY` (64 حرف hex).
2. `npm ci`
3. `npm run dev` (المنفذ 5000)، `npm test`، `npm run build` ثم `npm start`.
