# C — حلول المراجعة المستقلة

التاريخ: 2026-11-12 · الترحيل `0020_c_legacy` · التصميم `design.md`

## ما نُفّذ
- أداة ترحيل نظام المخصصات 1.2.0 (`npm run legacy:allowances`، و`control-app.bat legacyalw`). تقرأ النسخة الاحتياطية قراءة فقط، والتجربة تمشي نفس مسار التطبيق ثم تلغي المعاملة.
- الجداول:
  - `legacy_imports`: ثابت، والملخص يُكتب مرة واحدة.
  - `legacy_archive`: ثابت.
  - `data_issues`: ما تُحذف، ويتغير فيها الوضع والقرار فقط، وكل تغيير يُدقَّق.
- صفحة «حالات الاستفسار» (`/data-issues`)، ومساراها GET وPATCH.
- ملف تعريف جاهز لكشف الرواتب بصيغة Access (`sno`، `basic`، `m681`، `m802`).

## المراجعة وحلولها

| # | الملاحظة | الحل |
|---|---|---|
| H1 | فرد أُنهي ثم أُعيد إدخاله بالنظام القديم يُضاف مرة ثانية | ربط ثابت لكل فرد قديم (`member_link`). غير المربوط يُطابق بتاريخ الميلاد ضد كل أطفال HR غير المستعملين، ومنهم المربوطون بأفراد أُنهوا. الفرد المُنهى وغير المعاد ربطه يبقى ويصير حالة `legacy_member_ended`، ومثله الفرد المختفي من النسخة. اختبار: النسخة الثانية تطابق ولا تكرر |
| H2 | الأسباب القديمة لعدم الاستحقاق تُهمل، فقد يُصرف لطفل موقوف | تجاوز العمر يُنقل. الوفاة وزواج البنت والتوظيف تُنقل كحقيقة «ترحيل قديم». الحضانة والزوج يستلم والموقوف ما تُنقل وتصير حالة `legacy_member_not_imported`. `partner_employee_no` يُربط بـ `spouse_employee_id` |
| M1 | فرد حذفه المستخدم يُعاد، وتصحيح تاريخ ميلاد يولّد تكراراً | الربط الثابت: المربوط ما يُعاد ولا يُعاد مطابقته. اختبار: الزوجة المحذوفة ما رجعت |
| M2 | حاجز الفروق الرجعية يقارن نوع الخدمة نصاً خاماً | الفئة تُحسب بتطبيع المحرك (`normAr`)، ويُضاف إليها كل من احتُسب بالفترة. اختبار: نوع خدمة بمسافة زائدة مع فترة معتمدة يوقف التطبيق |
| M3 | اعتماد فترة أثناء الترحيل يضيّع الفروق | التطبيق يقفل `payroll_periods` بوضع `SHARE ROW EXCLUSIVE` لحين الالتزام |
| M4 | تاريخ إغلاق الحالة القديمة يصير اليوم، وقرار مختلق، وما في تحديث | تاريخ الإغلاق من النسخة. القرار الفارغ يُكتب «أُغلقت بنظام المخصصات بلا قرار مكتوب»، وهذا وصف للواقع. الحالة المغلقة لاحقاً بالقديم تُحدَّث إذا ما زالت مفتوحة هنا. الأرشيف بنسخة لكل تغيّر |
| M5 | تعارضات الحالة الزوجية تغرق حالات الاستفسار | تظهر بالتقرير فقط، والمقارنة بلا فرق التذكير والتأنيث (`عزباء` = `أعزب`) |
| M6 | فشل كتابة التقرير يظهر كفشل الترحيل، والتطبيق قد يأخذ نسخة غير اللي جُرّبت | التقرير بعد الالتزام بـ try، وبرسالة مستقلة. التجربة تحفظ الملف وبصمته، والتطبيق بـ `--from-last` يرفض إذا تغيّرت البصمة |
| M7 | القائمة تُقص عند 1000 بصمت | صفحات من 500 مع العدد الكلي، وزرّا السابق والتالي |
| L | `resolved_by` لكل حالة، وفاعل التدقيق | `resolved_by` للمحلولة والمستبعدة فقط، والـ CHECK يرفض الفارغ. فاعل التدقيق من `app.actor` بمعاملة المسار |
| L | قاعدة السجل الذاتي لحالة بلا موظف | المقارنة برقم الشركة أيضاً. تحقق حي: 403 |
| L | معرّف موظف أكبر من int4 بالفلتر | يرجع 400 (تحقق حي). رموز `%` و`_` تُهرَّب |
| L | فحص السبب بـ LIKE (1 يطابق 12) | تعبير نمطي بحد رقمي |
| L | سبب التمديد «null» | يُبنى من القيم الموجودة فقط |
| L | حذف موظف يفشل بلا رسالة واضحة | فحص الحذف يعدّ `data_issues` و`legacy_archive`، فيرجع 409 المعتاد |
| L | أرشيف التدقيق | قائمة سماح بالكيانات المالية والعائلية فقط، فلا دخول ولا كلمات مرور ولا إعدادات، وبلا عنوان IP |
| L | `applied_by` دائماً control-app | لوحة التحكم تمرر اسم مستخدم Windows |
| L | الأزواج المتعددون بـ HR | غير المطابق منهم حالة `legacy_spouse_hr_only`، والزوج الموقوف ما يُنقل |

**بقي كما هو:**
- **أرشيف موظفين غير موجودين بـ HR:** يُحفظ صفهم من كشف الرواتب للمطابقة لاحقاً. القسم 23 ينص على أن الاستيرادات تبقى.
- **ملف التقرير المحلي:** يحمل اسم الشركة، ويُنبَّه بالمخرجات على حذفه بعد المراجعة. مجلد `temp\` مستثنى من git.
- **اختبار القاعدة:** يترك سجلات ثابتة بقاعدة الاختبار. يُشغَّل على قواعد اختبار فقط.

## التحقق
- `typecheck:server`: 29 خطأ، نفس خط الأساس.
- vitest: 375 اختبار ناجح.
- اختبارات القاعدة: 71 ناجحة على قاعدة جديدة، تسلسلياً. منها 4 للترحيل: التجربة، والتطبيق والتكرار، والنسخة الثانية، والحاجز.
- الأداء: 5,196 موظفاً و8,700 فرد بـ 25 ثانية، والتكرار بـ 6 ثوانٍ.
- استعلامات القراءة على النسخة الحقيقية بجهاز عمر: كلها نجحت، والعدّ وحده خرج.
- الواجهة والمسارات بتشغيل حي:
  - القرار إلزامي للمحلولة.
  - فاعل التدقيق هو المستخدم.
  - السجل الذاتي برقم الشركة يرجع 403.
  - المعرّف الكبير يرجع 400.
