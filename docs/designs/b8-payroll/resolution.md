# B8 — حل ملاحظات المراجعة المستقلة على التصميم

التاريخ: 2026-11-10

النتيجة الأهم: الأجزاء اللي التصميم الأول عدّها «جاهزة للاستعمال» (السجل المؤرخ، السلّم، الأدوار) تسوي أقل مما افترضنا. فأُضيفت دفعة **B8a0** تصلحها قبل أي احتساب.

| # | الملاحظة | ما تغيّر بالتصميم |
|---|---|---|
| H1 | البصمة (أعلى وقت تسجيل + العدد) ما تلتقط التعديلات، ولا اعتماد عملية معلّقة، ولا تغيير خانة سلّم | البصمة صارت تجزئة لمجموعة المدخلات نفسها، بنفس لقطة القراءة، ويُعاد حسابها عند الاعتماد، مع قفل استشاري للفترة (3.8) |
| H2 | السلّم يُختار بعلم لا بتاريخ، وخانات النسخة النافذة تُعدَّل بلا أمر | النافذ بالتاريخ بين النسخ المعتمدة؛ قفل النسخة المستعملة؛ التغيير نسخة جديدة بمُعتمِد (3.0/4) |
| H3 | السجل المؤرخ مو بزمنين فعلياً: ما أحد يكتب التصحيح، وأغلب الحقول تتأرخ بيوم الإدخال، وإعادة التسمية تكتب تغييرات وهمية | الحقول المؤثرة بحركة مؤرخة فقط وتصحيح بـ `supersedes_id`؛ المشغّل يلتقط الإدراج ومعرّف الوحدة ويتجاوز إعادة التسمية؛ دالة `fieldAsOf` (3.0/1–3). **قرار لعمر** |
| H4 | الاعتماد الثاني ما يغطي العائلة ولا استمارة الموظف، والمعلّق يشيل الصف النافذ | العملية المعلّقة حمولة فقط تُطبّق عند الاعتماد؛ الاستبدال عند الاعتماد؛ العائلة تمر بالاعتماد (3.4، 3.5، 3.6) |
| H5 | بالأدوار الحالية المدير يقدر يسوي مديراً ثانياً ويعتمد لنفسه | أذونات رواتب لكل مستخدم تتقدّم من B9، ومنحها باعتماد ثانٍ، والربط بموظف إلزامي، وفحص «لا عملية على سجله» على كل المسارات (5.2). **قرار لعمر** |
| M1 | سطر «فرق التقريب» بلا سند، وكشوف الجهات تحتاج دنانير كاملة | أُزيل السطر؛ ثلاث خيارات لعمر (10/4) |
| M2 | المقابلات القانونية أعمدة غير مؤرخة ومربوطة بالأسماء | المستويات بمعرّفات الترميز داخل نسخة البند، فتغييرها نسخة بأمر ومُعتمِد (3.0/5) |
| M3 | حقول شروط غير متتبَّعة، والنص البديل يُقرأ قيمة | الشروط على الحقول المتتبَّعة فقط؛ الفارغ والبديل = تعذّر التقييم؛ الدرجات 11–13 بالتطبيع |
| M4 | قواعد إغلاق النسخ والإسنادات غير محددة، والتواريخ الشاملة | الاستبدال والتقسيم عند الاعتماد بمعاملة؛ شرط القيد على المعتمد غير المستبدل؛ `[من، إلى+1)`؛ قيود EXCLUDE بـ SQL يدوي |
| M5 | ثغرات بثبات اللقطة | `payroll_runs` ثابتة؛ مشغّلات على الإدراج وانتقالات الحالة؛ إلغاء الاعتماد بسبب ومُعتمِد؛ نسخة احتياطية قبل الاعتماد |
| M6 | التزامن | معاملة `REPEATABLE READ` وقفل استشاري لكل فترة |
| M7 | تغيّر الفئة خلال الشهر، ونوع خدمة غير مربوط | كل فئة تحتسب أيامها؛ النوع غير المربوط قضية جودة |
| M8 | ترحيل العائلة بقيم مخترعة | النمط الأولي «لم يُحدد»؛ قائمة «يحتاج تأكيد الدراسة»؛ جدول التمديدات؛ ربط الزوج الموظف |
| M9 | `salary_allowances` أُسقط | يُنقل إسنادات مسودة للمراجعة |
| M10 | مصدر بداية ونهاية الخدمة غير محدد | المباشرة من `current_appointment_date` أو صف الأساس؛ النهاية من تحوّل الحالة؛ الناقص قضية جودة |
| M11 | لا إذن لرؤية الرواتب | `payroll.read` |
| M12 | حصة الشركة تُعرض وهي مسودة؛ «بلا أولوية يُخفَّض أخيراً» قاعدة مخترعة | حصة الشركة ما تُعرض حتى ق-15؛ تفعيل بند داخل السقف بلا أولوية مرفوض |
| L | قواعد المتطلبات غير المذكورة (تاريخ التفعيل والأمر، قفل الاتجاه، دوائر الوعاء، منع الاعتماد بقيمة «يُتحقق»، الطباعة، التدقيق المحمي)، دقة القسمة، تخبئة المعاينة، الإجازة بدون راتب بـ B8a، الدرجات 11–13 | أُضيفت كلها (6، 4.1، 4.5، 7، 11) |

## باقٍ لعمر
القرارات 1 و2 و4 بالقسم 10 من التصميم.
