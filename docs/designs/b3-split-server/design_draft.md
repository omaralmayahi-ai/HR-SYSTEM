# B3 — تقسيم `server.ts`

الحالة: مسودة v1 — 2026-11-10 · يعتمد على: B2 (منجز) · بلا قرارات معلّقة

## 1. المشكلة (مقاسة عند 995f0bf)
- **الحجم:** `server.ts` فيه 11142 سطراً و206 مسارات، كلها داخل دالة واحدة `startServer()`، وفيها 49 مخزن `let inMemory*` مشتركاً بين المسارات.
- **لا فحص أنواع على الخادم:** `jsconfig.json` يشمل `src/**` فقط. أول فحص لـ `server.ts` (`tsconfig.server.json` الجديد) أظهر 127 خطأ، منها **2 خلل حقيقي يقع وقت التشغيل**:
  - `validateEmployeeImportRow` تُستدعى في الاستيراد الجماعي للموظفين ولم تُستورد ← `ReferenceError`: كل صف يُرفض أو يتعطل المسار.
  - `DELETE /api/trainers/:id`: المتغير `id` معرّف داخل `try`، ويُستعمل بعدها ← `ReferenceError` بعد حذف المدرب من القاعدة، فالطلب يفشل رغم أن الحذف تم.
- **أثر الحجم:** تعديل أي مسار يتطلب قراءة ملف بحجم 11 ألف سطر، والوكلاء والمراجعون لا يستطيعون رؤيته كاملاً. هذا سبب أغلب الأخطاء المكررة التي ظهرت في المراجعة الأولى.

## 2. الهدف
- `server.ts` يصبح إقلاعاً فقط (≤ 300 سطر): الإعداد، والبوابة، والترحيلات، وتسجيل المسارات، والتشغيل.
- كل مجال في `server/routes/<المجال>.ts` يصدّر `register<Domain>Routes(app, ctx)`.
- `ctx` (`server/context.ts`) يحمل المشترك صراحة: `db`، و`schema`، و`pool`، والوسطاء، ومساعدات الأخطاء، ومحرك الترفيع، ودوال إعادة الاحتساب. لا مخازن ذاكرة مشتركة فيه.

## 3. القاعدة الحاكمة: نقل بلا تغيير سلوك
- **كل PR ينقل مجالاً أو أكثر نقلاً حرفياً.** الاستثناء الوحيد: حذف فروع الذاكرة الميتة في المجال المنقول (B2g). بعد B2d/B2f لا تُبلَغ هذه الفروع إلا في سباق نادر، وحذفها يزيل الحالة المشتركة القابلة لإعادة الإسناد (`let`) التي تمنع النقل إلى وحدة مستقلة.
- **مخزن ذاكرة يُستعمل لغير الرجوع الاحتياطي** (سياق محرك الترفيع، القوائم الافتراضية القانونية): يُستبدل بقراءة من القاعدة، أو بثابت مُصدَّر، ويُذكر في وصف الـ PR.

## 4. شبكة الأمان (أول PR، قبل أي نقل)
1. **`tsconfig.server.json` + `npm run typecheck:server`:** خط أساس مقاس لعدد الأخطاء. الشرط: **صفر `TS2304` (اسم غير معرّف)**، وعدد الأخطاء الكلي لا يزيد عن خط الأساس. النقل الناقص يظهر فوراً كـ `TS2304`.
2. **لقطة جرد المسارات** (`server/routeInventory.test.ts`): تستخرج كل `app.<method>('<path>'` من `server.ts` و`server/routes/*.ts` وتقارنها بلقطة محفوظة. مسار يضيع أو يتكرر يُفشل الاختبار.
3. **اختبار دخان للإقلاع:** يبني `dist/server.cjs` ويشغّله على قاعدة مؤقتة إن توفّر `TEST_DATABASE_URL`، ثم يطلب `/api/health` ومسارات محمية (يُتوقع 401 لا 500).
4. **إصلاح الخللين أعلاه** مع اختبار لكل منهما.
