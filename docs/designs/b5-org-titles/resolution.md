# B5 — التشكيلات والعناوين الوظيفية: النطاق ومعالجة المراجعة المستقلة

التاريخ: 2026-11-10 · القرارات: ق-7 (نبدأ بالعناوين الموجودة وتُكمَّل)، ق-8 (الديانة والقومية تبقى كما هي)

## ما نُفّذ
- `org_units`: رمز ثابت (`OU-0001`…)، `valid_from/valid_to`، مفتاح أجنبي للأب (NOT VALID).
- `employees.org_unit_id` (مفتاح أجنبي RESTRICT، NOT VALID) مربوط بالمسار الكامل المحفوظ بالشعبة، ثم باسم وحدة وحيد.
- إعادة تسمية الوحدة أو نقلها تحدّث القسم والشعبة لموظفيها وفروعها بنفس المعاملة، ويُسجَّل بالسجل المؤرخ بسبب واضح.
- الحذف للوحدة المضافة بالخطأ فقط (بلا موظفين بالمعرّف أو بالاسم)؛ وإلا «إنهاء الوحدة» بتاريخ يشمل الفروع ويُرفض إذا بيها موظفون.
- العناوين: السند القانوني وتواريخ النفاذ والدرجة العليا (`grade_max ≤ min_grade` لأن الدرجة 1 أعلى درجة). `GET /api/job-titles` ما يزرع عناوين من الكود.

## ملاحظات المراجعة المستقلة
| الملاحظة | ما تم |
|---|---|
| حفظ الموظف (حتى تغيير الهاتف فقط) يعيد كتابة الشعبة من الوحدة | `attachOrgUnit` يقارن بالمعرّف الحالي؛ نفس الوحدة = ما يلمس النصين. اختبار حي: صفر صفوف بالسجل |
| زر «لم يحدد بعد» ما يفك الربط | يرسل `org_unit_id: null`، والخادم يفك الربط |
| تعديل وحدة أبوها مفقود يُرفض | الأب يُفحص فقط إذا تغيّر |
| الاسم الملتبس يمسح ربطاً موجوداً، والاستيراد يبتلع الأخطاء ويحمّل الوحدات لكل صف | ما يُغيَّر الربط إذا ما تحدد؛ الاستيراد يبتلع أخطاء المستخدم فقط ويحمّل الوحدات مرة |
| الإنهاء بتاريخ مستقبلي يقفل حفظ موظفيها لاحقاً | الربط بوحدة لها تاريخ إنهاء (منتهية أو مجدولة) مرفوض، والفحص فقط عند تغيير الوحدة؛ PUT بـ valid_to يشمل الفروع |
| إعادة التسمية بلا فحص تكرار | يُرفض نفس الاسم تحت نفس الجهة الأعلى |
| نهايات أسطر JobTitlesSettings.jsx | أُعيدت CRLF |
| رسالة CHECK غير واضحة عند تغيير الدرجة الدنيا | رسالة عربية قبل الحفظ |
| الرموز المكررة تتخطى فهرس التفرد بصمت | مقبول مؤقتاً: الترحيل ما يفشل على بيانات التشغيل؛ يُضاف للتقرير لاحقاً |
